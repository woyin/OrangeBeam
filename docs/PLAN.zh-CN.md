# 实现计划

状态：2026-09-22 更新。已确认仅做 macOS Apple Silicon，第一代 Spotlight，蓝牙优先并支持 USB。Windows 延后。用户已连接蓝牙设备，聚光跟随、按住静止保持、松开隐藏三项已完成实机验收。

## 产品范围

复现演示所需的三种核心指示效果：聚光（周围压暗）、实时放大、数字激光。保留系统原有翻页和鼠标行为，随后增加双击切换、按钮长按、电量、计时和震动提醒。先完成单平台，再复用 Rust 核心扩展另一个平台。

当前为 0.2.0 开发预览：原生界面与效果已实现，顶键通过真实 HID++ 通知接入。23 项测试与三种原生绘制检查通过；蓝牙聚光核心联动和同进程手动重连已实测。实时放大本轮未获得画面，USB、完整演示场景与高级按键功能仍待完成。下面各里程碑按各自验收项判断，不因局部通过而整体标记完成。

## 架构选择

Rust 负责设备发现、HID++ 协议、连接状态、事件状态机、配置和定时。
绘制层采用系统原生透明窗口，通过 Rust 绑定调用平台接口。
macOS 已采用 AppKit NSView 绘制与 ScreenCaptureKit 采集。每个显示器独立使用点击穿透、非激活窗口。Windows 的窗口和采集方案留待后续阶段，不在当前验收范围。

不先引入跨平台 WebView。设备事件与渲染之间只传递语义事件，平台窗口和采集 API 留在独立模块。聚光/激光运行时不启动屏幕采集，效果关闭时停止绘制循环；实际 CPU、内存、启动耗时和分发体积在可运行版本测量。

## 当前进展

- M0：蓝牙查询、电量、映射和顶键/前进键已有实机样本；USB 和其他按键动作待验证。
- M1：蓝牙聚光跟随/静止保持/松开隐藏已通过；激光、快捷键、多屏/全屏和点击穿透待验收。
- M2：放大绘制通过合成图验证；真实屏幕采集、视频连续更新、排除自身及停止采集仍待授权后的端到端检查。
- M3：仅临时接管顶键，退出恢复并校验，CLI 电量读取成功；GUI 采用明确按住/松开通知，支持手动断开/重连。双击、其他长按配置、GUI 电量和震动待实现。
- M4：本地 ARM64 app 打包完成；公开分发签名、公证、CI 和完整场景验收未完成。

| 阶段 | 交付 | 验收 |

| M1 聚光与激光 | 原生覆盖层、菜单栏/托盘、无设备演示模式 | 聚光区域透明、周围压暗；激光位置正确；窗口不抢焦点、不挡点击；翻页保持正常；一键关闭/退出 |
| M2 实时放大 | 采集、放大镜、权限提示、缩放设置 | 文字、视频均实时更新；采集排除自身覆盖层；授权拒绝后聚光与激光仍可用；停止放大即停止采集 |
| M3 设备完整交互 | 顶键触发与双击切换、长按、电量和定时震动 | 保持顶键静止时效果正确；普通鼠标不误触发；断连效果消失；重连恢复；只有支持的功能可启用 |

每个阶段保留无设备测试入口，但演示成功不能替代实机测试。

## 必须先解决的设备问题

1. 通过报文或系统 HID usage 验证顶键触发方式。鼠标移动事件不能直接等同于“按住顶键”；单纯静止超时会导致按住不动时聚光错误消失。
2. 查询 ROOT 得到功能索引；USB 与蓝牙分开确认报文格式、槽位、访问权限。
3. 确认需要接管的具体按键，尽可能保持系统默认翻页。若必须修改运行期配置，记录原值并在正常退出时恢复；还要实测崩溃和断连是否自动恢复，不能只依赖析构函数。
4. Spotlight 2 独立进行型号和槽位发现；共享 Bolt 接收器不能作为设备身份。

## 屏幕与权限边界

- 坐标统一到明确的逻辑坐标系，显式转换 Retina/DPI、屏幕偏移和上下原点差异。
- 测试副屏在左侧/上方、不同缩放比例、插拔投影仪、镜像与扩展屏、全屏演示和 Spaces。
- 覆盖窗口鼠标穿透且不激活，退出时隐藏窗口和恢复任何已修改的光标状态。
- 屏幕共享需要分开验证“共享整个显示器”和“仅共享演示窗口”。独立覆盖窗口不能保证被单窗口共享捕获，必须如实记录支持范围。
- 权限按功能申请；聚光不应为了将来的放大功能预先强制要求屏幕采集。

## 测试顺序

先用录制报文测试状态机、短按/长按/双击、丢失释放事件和断连。再在目标系统测试无设备演示、焦点和点击穿透，随后接真实遥控器。最后完成 Keynote/PowerPoint 或用户实际演示软件的全屏、多屏与会议共享场景。

性能目标先作为待测预算：发布包希望控制在 20 MB 以内，空闲时无持续高频绘制/采集。是否达到目标由构建产物和实测决定，不因使用 Rust 自动成立。
